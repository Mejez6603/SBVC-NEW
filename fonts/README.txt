         the licence texts are published with each family on https://fonts.google.com.
fonts.css tells the pages which file to use.

Their licences (SIL Open Font License, or Apache 2.0 for some) are shown on each family's page on https://fonts.google.com.
"Futura" in the font menus is not a file here: it uses a Futura installed on the computer, otherwise Jost.
To add a font to the menus, add its rules to fonts.css and its name to FONT_NAMES in js/state.js.
