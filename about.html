SBVC - Show Bible Verse Controller

Description

SBVC presents Bible passages and hymns for church services and Bible studies. The operator works in the Controller window; the audience sees only the clean Presentation window on a second screen or projector.

This is the static version: plain HTML, CSS, JavaScript and data files. No build step and no Node.

How It Works

  1. Choose a verse in the controller. It is written to localStorage.
  2. The presentation window listens for storage events and redraws instantly.
  3. Theme, fonts, sizes, colours and text positions travel the same way.

Both windows must be in the same browser and profile on the same computer.

Running It

Double-click START.bat, then open http://localhost:8765/controller.html. Press Show to open the presentation window, and F to go fullscreen.
